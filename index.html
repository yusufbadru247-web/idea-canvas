Gestures

New note
Double-click or double-tap the canvas
Edit
Double-click a card
Move around
Drag the canvas, scroll, or one finger
Zoom
Pinch, or Ctrl/⌘ + scroll
Connect
Select a card, drag its round handle onto another card (or onto empty space for a new note)
Add
Paste anything, or drop files
Select more
Shift + click
Delete
Delete or Backspace
Duplicate
Ctrl/⌘ + D
Fit all
Shift + 1, or tap the zoom %
Search
Ctrl/⌘ + K, or /
Format
Use the bar above a note while writing, or Ctrl/⌘ + B, I, K
Lists
Enter continues a list; Enter on an empty item ends it
To-dos
Tap a checkbox to tick it, no need to edit
Pages
P, or the Page button. Inside a page, type / for headings, to-dos, a divider, a photo or a page inside it
Undo
Ctrl/⌘+Z, or the arrows in the bottom bar; Ctrl/⌘+Shift+Z or Ctrl+Y to redo. While typing in a note, it undoes the text first
Capture
C, or the lightning button: type, dictate or add a photo; it lands in your Inbox to sort later with Move
AI
Select cards and press ✦ AI, or use ✦ in a page: summary, next steps, tasks, mind map, or ask a question
Embeds & PDFs
Links to Google Docs, Sheets, Slides, Figma, Spotify, Vimeo, Loom, Canva, Instagram, TikTok or Maps get “Show here”. On a page, a link alone on its line shows inside the page. PDFs open in a reader
Trash
Board menu, then Trash: deleted cards stay 30 days and can be restored. Pages keep earlier versions under the clock button
Tags
Write #idea in a note or a page, or use Tags on any card. Tap a tag to see everything with it
Links
Type [[ in a note or a page and pick a card, or write [[A new name]] to make a page. Each page lists what links to it
Tables
T, the Table button, or /table in a page. Click a column name to rename it, change its type or sort; switch to Board to see cards by Status
Dates
Add @today, @friday, @25/11 or /date to a to-do, then tap the date to change it
Today
The calendar button: overdue, today, this week
Mind maps
M, or the Map button. Click an idea to open it (notes, links, photos), + to add one, drag to move it. A map made from a page follows that page
